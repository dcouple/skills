# Writing framework

The maintained process is [seo-writing-framework](seo-writing-framework/SKILL.md). Read that skill when drafting; use [good-writing-fundamentals](good-writing-fundamentals/SKILL.md) for line edits or a detect-only review.

## The short version

1. Establish the reader's job, facts, and voice.
2. Research actual gaps; use examples where helpful.
3. Draft the answer and a clear next action.
4. Read as the recipient: what is missing, confusing, or unsupported?
5. Edit for clarity without losing voice or useful detail.
6. Verify claims and obtain any required approval before publication.

## Examples

- Pricing email: state the change, affected customers, date, and options.
- Blog post: answer the searcher's question before promoting a product.
- Documentation: give usable steps, prerequisites, and a result check.
